# Abzaro Desktop — نسخه آزمایشی ویندوز

این بسته یک نسخه آفلاین از خروجی استاتیک سایت به همراه تبدیل محلی DOCX به PDF است. نصب‌کننده ویندوز x64 دارای LibreOffice 26.2.7 است و اگر LibreOffice در مسیر متعارف نصب نباشد نصب آن را آغاز می‌کند. نصب همه کاربران و LibreOffice به دسترسی مدیر نیاز دارد. LibreOffice یک برنامه جداگانه است و با حذف ابزارو پاک نمی‌شود. در صورت شکست نصب LibreOffice، آن را از libreoffice.org به صورت دستی نصب کنید. ویندوز ARM و نسخه‌های دیگر فعلاً آزموده نشده‌اند.

## نصب و آزمون
1. نصب‌کننده را از منبع مورد اعتماد دریافت و اجرا کنید. این نسخه آزمایشی امضای دیجیتال ندارد و ممکن است Windows SmartScreen هشدار بدهد؛ در صورت عدم اعتماد اجرا نکنید. در هنگام نصب به حساب مدیر و فضای دیسک کافی نیاز است.
2. پس از پایان نصب، Abzaro Desktop را باز کنید. بخش «تبدیل Word به PDF» را باز و فایل DOCX بدون رمز، حداکثر ۲۰ مگابایت، انتخاب کنید.
3. دکمه تبدیل را بزنید و مقصد PDF را انتخاب کنید. پردازش با LibreOffice روی کامپیوتر انجام می‌شود؛ برای تبدیل فایل به سرور آپلود نمی‌شود. کیفیت به فونت‌های نصب‌شده و ویژگی‌های سند وابسته است.
4. بستن برنامه اینترنت را برای برنامه فعال نمی‌کند؛ نسخه آزمایشی درخواست‌های شبکه صفحه را مسدود می‌کند. سرویس‌های آنلاین و لینک‌های خارجی در این نسخه در دسترس نیستند. عملکرد تمام ابزارهای موجود سایت در بسته دسکتاپ تضمین نشده است. موتور FFmpeg.wasm در بسته موجود است ولی همه ابزارهای سایت در ویندوز آزمون نشده‌اند.
5. فایل‌های موقت معمولاً پس از تبدیل پاک می‌شوند؛ در قطع ناگهانی برنامه یا سیستم احتمال باقی ماندن آن‌ها در پوشه موقت ویندوز وجود دارد. LibreOffice با پروفایل موقت و محدودیت ماکرو و به‌روزرسانی پیوند اجرا می‌شود، ولی برای اسناد ناشناس ایزوله‌سازی کامل امنیتی فراهم نشده است. برای اسناد حساس یا ناشناس اتصال شبکه را قطع کنید.

## ساخت از سورس
روی Windows x64 با Node 20 یا جدیدتر و PowerShell در ریشه پروژه:
```
npm ci
npm run build:static
cd desktop
npm ci
node scripts/fetch-office.mjs
npm run dist:win
```
خروجی `desktop/release/Abzaro-Desktop-Setup-0.1.0.exe` است. برای دانلود LibreOffice و وابستگی‌ها اتصال لازم است؛ دریافت MSI رسمی با هش SHA-256 ثابت بررسی می‌شود. مجوز LibreOffice و Electron و دیگر وابستگی‌ها باید پیش از انتشار عمومی بررسی و رعایت شوند. برای توزیع عمومی امضای کد، به‌روزرسانی امن، آزمون ویندوز و بررسی امنیت لازم است.

## ساخت با GitHub Actions
پس از قرارگرفتن کد در مخزن، در GitHub زبانه Actions را باز کنید، Build Windows desktop trial را انتخاب و Run workflow را بزنید. پس از موفقیت، از صفحه اجرای workflow فایل Abzaro-Desktop-Windows-x64 را در Artifacts دریافت کنید. فایل artifact یک ZIP است و نصب‌کننده داخل آن است. امکان اجرا به فعال‌بودن Actions و سهمیه مخزن بستگی دارد و artifact پس از یک روز حذف می‌شود. نصب‌کننده نسخه آزمایشی و بدون امضای دیجیتال است.
