# ابزارو (Abzaro)

مجموعه‌ای از ابزارهای آنلاین رایگان برای کاربران فارسی‌زبان. همهٔ پردازش‌ها در مرورگر کاربر
انجام می‌شود و هیچ داده‌ای به سرور ارسال نمی‌شود.

## اجرا

```bash
npm install
npm run dev          # http://localhost:3000
```

برای اجرای نسخهٔ پروداکشن:

```bash
npm run build
npm start
```

## اسکریپت‌ها

| دستور | کار |
| --- | --- |
| `npm run dev` | سرور توسعه |
| `npm run build` | بیلد پروداکشن |
| `npm start` | اجرای بیلد |
| `npm run typecheck` | بررسی TypeScript |
| `npm test` | تست‌های واحد (۱۲۱ تست) |
| `npm run test:e2e` | تست تعاملی سه ابزار متنی در مرورگر واقعی |
| `npm run test:e2e:all` | تست تعاملی هر ۲۵ ابزار (۹۱ سنجه) |
| `npm run build:static` | خروجی کاملاً استاتیک در `out/` |
| `npm run package:static` | ساخت `abzaro-static.zip` برای Netlify Drop |

`npm run test:e2e` به یک سرور در حال اجرا نیاز دارد و به‌صورت پیش‌فرض به
`http://localhost:3000` وصل می‌شود. برای تست پروداکشن:

```bash
BASE_URL=http://localhost:3100 npm run test:e2e
```

## ابزارهای پیاده‌سازی‌شده

همهٔ ۲۵ ابزار کامل و کاربردی‌اند — هیچ placeholder یا برچسب «به‌زودی» باقی نمانده است.

### متن و ویرایش
- **شمارش کلمات** — کلمات، کاراکتر (با/بدون فاصله)، جمله، پاراگراف، خط، زمان مطالعه و گفتار
- **شمارش کاراکتر** — شمارش دقیق با نیم‌فاصله، حجم UTF-8، نوار پیشرفت محدودیت ۱۶۰/۲۸۰
- **پاک‌سازی متن فارسی** — یکسان‌سازی «ی/ک» عربی، حذف فاصله‌های اضافی و کاراکترهای نامرئی،
  ۶ قاعدهٔ مستقل با امکان روشن/خاموش کردن، شمارش تغییرات و درج متن نمونه

### اعداد و محاسبات
- **تبدیل اعداد به فارسی** — تبدیل دوطرفهٔ ارقام فارسی/عربی/انگلیسی با جداکنندهٔ هزارگان فارسی
- **تبدیل عدد به حروف** — مناسب فاکتور و چک؛ تا ۱۰^۱۸، اعشار («ممیز»)، اعداد منفی
- **محاسبه درصد** — سه حالت: درصد از عدد، چند درصد است، تغییر درصدی
- **محاسبه تخفیف** — تخفیف درصدی، تخفیف مبلغی، و بازیابی قیمت اصلی از قیمت نهایی
- **محاسبه سن** — تاریخ شمسی با تبدیل دقیق جلالی↔میلادی، روز هفتهٔ تولد، روز تا تولد بعدی
- **محاسبه اقساط وام** — فرمول مستهلک با جدول کامل بازپرداخت (قسط، سود، مانده)
- **محاسبه BMI** — دسته‌بندی WHO، محدودهٔ وزن سالم و وزن ایده‌آل
- **اختلاف دو تاریخ** — سال/ماه/روز، هفته، ساعت و دقیقه، روز هفتهٔ هر دو تاریخ
- **سن دقیق** — تا ساعت و دقیقه، مجموع روزها/ساعت‌ها، برج و شمارش تا تولد بعدی

### تصاویر
- **تغییر اندازه تصویر** — کشیدن و رها کردن فایل، قفل نسبت ابعاد، پیش‌فرض‌های عرض،
  خروجی JPG/PNG/WebP، پیش‌نمایش و دانلود
- **فشرده‌سازی تصویر** — سه سطح کیفیت، کوچک‌کردن تا ۱۲۸۰px، خروجی JPG/WebP و مقایسهٔ حجم قبل/بعد
- **تبدیل عکس به PDF** — چند تصویر در یک PDF، ترتیب قابل تغییر، اندازهٔ A4/Letter/هم‌اندازهٔ تصویر،
  جهت و حاشیهٔ دلخواه (ساخته‌شده با pdf-lib در مرورگر)
- **تبدیل PDF به عکس** — رندر صفحه‌ها با pdf.js در سه کیفیت (۷۲/۱۴۴/۲۱۶ dpi)، بازهٔ صفحه
  (`1-3, 5`)، خروجی JPG/PNG و دانلود تکی یا ZIP (JSZip)
- **تبدیل JPG/PNG/WebP** — تبدیل قالب با کنترل کیفیت و مقایسهٔ حجم قبل/بعد
- **عکس به Base64** — خروجی خالص، data URI، CSS و تگ `<img>` با کپی یک‌کلیکی
- **ساخت عکس پروفایل** — برش مربع، بزرگ‌نمایی، شکل دایره/گوشه‌گرد/مربع، پس‌زمینهٔ دلخواه، خروجی ۲۰۰ تا ۱۰۲۴ پیکسل

### ویرایش فایل و PDF
- **فشرده‌سازی PDF** — دو روش: بازنویسی بدون افت کیفیت (pdf-lib) یا رندر صفحه‌ها به JPEG در سه کیفیت
- **ادغام PDF** — ترتیب دلخواه فایل‌ها، کپی صفحه‌به‌صفحه بدون افت کیفیت (pdf-lib)

### برنامه‌نویسی و وب
- **تولید QR Code** — متن/لینک/WiFi/تلفن/ایمیل، سه اندازه، چهار رنگ، چهار سطح ECC، دانلود PNG
- **JSON Formatter** — مرتب‌سازی، فشرده‌سازی، مرتب‌سازی کلیدها، تعمیر خودکار، خطا با شماره خط و ستون
- **Base64 Encoder/Decoder** — پشتیبانی کامل UTF-8 (فارسی)، حالت URL-safe
- **URL Encoder/Decoder** — سه حالت (Component / URI / Safe) با خطای فارسی برای رشتهٔ نامعتبر
- **فشرده‌سازی تصویر** — سه سطح کیفیت، محدود کردن ابعاد، مقایسهٔ حجم قبل/بعد و درصد کاهش

هر دو ابزار تصویری با Canvas کار می‌کنند: فایل هرگز آپلود نمی‌شود.


## دیپلوی

راهنمای کامل در [`DEPLOY-NETLIFY.md`](DEPLOY-NETLIFY.md) آمده است. خلاصه:

```bash
npm run package:static      # ساخت zip آمادهٔ آپلود در app.netlify.com/drop
```

یا برای دیپلوی خودکار، repo را به Netlify وصل کنید تا هر `git push` منتشر شود.
`netlify.toml` از قبل تنظیم شده است.

**مهم:** متغیر `NEXT_PUBLIC_SITE_URL` را در پنل Netlify تنظیم کنید — چون `Header` و
`ContactForm` کامپوننت کلاینتی‌اند و این مقدار باید در زمان build موجود باشد.

## متغیرهای محیطی

`.env.example` را به `.env.local` کپی کنید:

```bash
NEXT_PUBLIC_SITE_URL="https://abzaro.ir"
```

این مقدار در متادیتا، canonical، `sitemap.xml` و `robots.txt` استفاده می‌شود.

## نکتهٔ دامنهٔ پیش‌نمایش

در `next.config.ts` گزینهٔ `allowedDevOrigins` تنظیم شده است. Next.js به‌صورت پیش‌فرض
درخواست فایل‌های جاوااسکریپت از دامنه‌ای غیر از `localhost` را در حالت توسعه مسدود
می‌کند؛ اگر آن را تنظیم نکنید صفحات نمایش داده می‌شوند اما هیچ کامپوننت تعاملی (ابزارها،
جستجو، فرم) کار نمی‌کند. الگوهای مجاز در حال حاضر `**.e2b.app`، `**.e2b.dev` و
`**.arena.ai` هستند. اگر روی دامنهٔ دیگری پیش‌نمایش می‌گیرید، آن را به این فهرست اضافه کنید.


## نکات پیاده‌سازی

**تقویم شمسی از صفر نوشته شده.** `src/lib/jalali.ts` الگوریتم رسمی جلالی (جدول
`BREAKS`) را پیاده می‌کند — بدون هیچ وابستگی. با تست‌های شناخته‌شده اعتبارسنجی شده است
(مثلاً ۱۴۰۳-۰۱-۰۱ = ۲۰۲۴-۰۳-۲۰ و ۱۴۰۳ سال کبیسه است پس اسفند ۳۰ روز دارد).

**نیم‌فاصله (U+200C) هرگز به‌عنوان فاصله شمرده نمی‌شود.** در شمارش کلمات و در پاک‌سازی
متن، «می‌خواهم» یک کلمه است و نیم‌فاصله حفظ می‌شود، چون بخشی از املای درست فارسی است.

**همهٔ ارقام نمایش‌داده‌شده فارسی‌اند**، با جداکنندهٔ هزارگان فارسی (٬ U+066C) و ممیز
فارسی (٫ U+066B). این کار در `formatFa` در `components/tools/shared.tsx` متمرکز شده است.

**ورودی‌های عددی، ارقام فارسی را هم می‌پذیرند.** کاربر می‌تواند «۱۳۷۰» یا «1370» تایپ
کند؛ مقدار نمایش‌داده‌شده همیشه فارسی است ولی در state داخلی لاتین نگه داشته می‌شود.

**ابزارهای تصویری به Canvas متکی‌اند و آپلود نمی‌کنند.** `createImageBitmap` فایل را
می‌خواند، روی canvas کشیده می‌شود و `canvas.toBlob` خروجی را می‌سازد. `ImageBitmap` پس
از استفاده `close()` می‌شود و object URLها هم پاک می‌شوند تا حافظه نشت نکند.
